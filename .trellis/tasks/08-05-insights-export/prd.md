# 报表洞察与导入导出

## Goal

补齐「做完了看不清趋势」与「数据迁不走」：仪表盘增加基础吞吐/趋势洞察；支持任务域 JSON（优先）导入导出，SQL 备份之外多一条业务迁移路径。

## Background

- 仪表盘已有统计卡、分布、活动、员工绩效；无燃尽/趋势序列。
- 备份：`backup_database` SQL 级；无任务 JSON/CSV。

## Requirements

### R1 洞察

- 至少：按日/周任务完成数趋势；进行中老化（可选）；按项目或全局过滤。
- 数据全部经 Rust command 聚合，前端只展示。

### R2 导出（仅任务域 JSON）

- 导出选中项目或筛选结果的**任务**（含：标题、状态、优先级、描述、标签名、子任务、依赖 id 可选等）。
- 格式：**仅 JSON**（v1 不做 CSV）。
- 不含项目实体、员工实体、密钥、SSH 配置。

### R3 导入

- 导入任务 JSON 到指定项目（冲突策略：跳过 / 新建；design 定默认）。
- 校验错误可读；写 activity。

### R4 安全

- 导入不执行任意 SQL；附件二进制 v1 不纳入（可忽略或占位说明）。

## Key Decisions

| 决策 | 结论 | 日期 |
|------|------|------|
| 导入导出范围 | 仅任务域 JSON | 2026-08-05 |

## Acceptance Criteria

- [ ] 仪表盘可见至少一种趋势图/序列表
- [ ] 任务 JSON 导出后再导入可还原关键字段（往返烟测）
- [ ] 导出文件不含员工/SSH 密钥
- [ ] SSH/本地项目过滤正确
- [ ] build + clippy 通过

## Out of Scope

- 项目/员工整包迁移（仍用 SQL 备份）
- CSV 格式
- Jira/Linear OAuth 双向同步
- 完整 BI 报表平台
