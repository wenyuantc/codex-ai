# 首次使用引导 checklist

仪表盘展示首次使用 checklist：SDK 健康 → 可选 SSH → 项目 → 员工 → 首任务；每步可跳转；可关闭并记住。

## Acceptance

- [ ] Dashboard 显示 checklist，步骤可导航到设置/项目/员工/看板
- [ ] 步骤完成状态基于真实数据（health / projects / employees / tasks）
- [ ] 可关闭；localStorage 记住 dismiss
- [ ] SSH 模式下 SSH 步骤可见且链到 `/settings?section=ssh`
