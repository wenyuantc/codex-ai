# 任务项目文件引用

## Goal

新建任务时，必须先选项目才能引用该仓库里的文件；任务详情可以继续增删引用。运行任务时，引用的相对路径进入发给 AI 的提示词，员工优先阅读这些文件。这与「附件」（拷贝到应用托管目录）是两套能力。

## Background

- 现有附件走系统文件对话框，不限制项目目录，文件会被复制。
- AI 执行提示词由前端 `buildTaskExecutionInput` 组装；协调员计划与自动质控修复提示词在 Rust 侧组装。
- 本地与 SSH Git 操作统一走 `git_runtime` + `git_bridge.mjs`。
- 仓库要求新功能兼容 SSH；新 activity key 必须有中英仪表盘文案。

## Requirements

1. 未选项目时，「选择项目文件」禁用并说明原因；选了项目后可搜索多选仓库内文件。
2. 换项目时清空已选引用（与标签/依赖一致）。任务详情项目已绑定，始终可改引用。
3. 引用存相对仓库根路径，不复制文件。禁止 `..`、绝对路径、空路径。
4. 选择器是应用内弹窗：搜索 git 跟踪文件与未跟踪文件。本地和 SSH 同一套，不用系统文件对话框。
5. 新建任务和任务详情都能看到 chip 列表，并可添加/移除。
6. 运行、创建并执行、协调员计划、自动质控修复提示词都包含「项目文件引用」路径列表。不内联文件内容。
7. 活动日志：`task_file_refs_added`、`task_file_ref_removed`；创建任务细节可带引用数量。zh-CN + en。
8. 文件在磁盘上消失不阻断运行；选择时只能从 git 列表勾选。

## Out of Scope

- 把文件内容塞进提示词
- 引用目录
- 任务模板 / JSON 导入导出带引用
- Monaco `@file` 自动补全
- 看板卡片显示引用数量
- 改附件拷贝/传图行为

## Acceptance Criteria

- [ ] 未选项目时无法打开「选择项目文件」；选项目后可搜索并多选
- [ ] 换项目清空已选引用
- [ ] 创建后引用落库；详情可添加/删除
- [ ] 引用是相对路径，不复制文件；附件行为不变
- [ ] 本地与 SSH 项目都能选文件
- [ ] 运行 / 创建并执行 / 协调员计划 / 自动修复提示词包含路径列表
- [ ] 仪表盘活动有中文：添加/移除项目文件引用
- [ ] 含 `..` 或绝对路径的写入被后端拒绝
