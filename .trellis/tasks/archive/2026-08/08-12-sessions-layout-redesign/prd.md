# 优化对话管理页布局

## Goal

对话管理页（`/sessions`）布局"有点乱"：以 UI 设计视角重构页面，改为 **卡片 + 表格混合视图（可切换，默认卡片）**，收敛筛选区与视觉噪音，提升信息层级与一屏信息密度。现有功能（搜索、筛选、分页、续聊、停止、日志、变更查看、刷新快捷键、全局搜索高亮定位）全部保留。

## Background（代码勘察确认）

实现位于 `src/pages/SessionsPage.tsx`（约 950 行单文件）。当前痛点：

- 筛选区两大行栅格（3 搜索框 + 4 下拉 + 1 复选），视觉重量超过数据区
- 状态列竖排 4 个 Badge（类型/状态/本地或SSH/续聊状态），操作列最多竖排 4 个按钮 + 提示文本，单行动辄 100px+
- 会话列堆叠 名称+ID+摘要+内容预览；任务列最多 4 行；员工列含 break-all 长路径
- 结果：一屏仅见 2~4 条会话

约束事实：

- 文案走 i18n `sessions` namespace，新增 key 需补 zh-CN + en（`src/locales/{zh-CN,en}/`）
- 时间展示走 `formatDate()`；组件用 `@/components/ui/*` + TailwindCSS 4
- 筛选/分页为前端 `filteredSessions` useMemo，与布局解耦，重构不动数据流
- 全局搜索跳转依赖 `session-row-${session_record_id}` DOM id 高亮定位（两种视图都要保留此锚点）
- 本地/SSH 模式都是一等公民：`execution_target`、`target_host_label`、artifact 受限提示（`SshArtifactLimitedNotice`）必须可见

## Requirements

1. **混合视图**：标题栏右侧提供卡片/表格视图切换；首次访问默认卡片视图；选择持久化到 localStorage，之后进入保持上次选择
2. **卡片视图**：
   - 主行：会话名称 + 主状态 Badge（运行中需醒目）
   - 辅助行：Provider、类型（执行/审查）、本地/SSH、更新时间（formatDate）
   - 关联行：任务标题、员工名（缺省显示未关联/未绑定）
   - 操作区紧凑化：「继续」为主按钮，日志/变更/停止收进次要按钮或更多菜单
3. **表格视图紧凑化**：状态列合并为 1 个主状态 Badge + 行内小标识；操作列直出按钮不超过 2 个，其余收进菜单；摘要/内容预览/工作目录截断并带 title 悬浮
4. **筛选区收敛**：默认单行（内容搜索 + 状态筛选 + 视图切换 + 刷新）；会话ID/任务ID/类型/Provider/员工/仅失败 折叠进「更多筛选」展开面板，激活的非默认筛选有数量标记
5. **功能回归**：搜索、筛选、分页、刷新（R）、高亮定位、续聊、停止、日志、变更在两种视图下全部可用；SSH 信息在两种视图下可见
6. **i18n**：新增/修改文案 zh-CN + en 齐全

## Key Decisions

- 布局方向：表格 + 卡片混合视图，可切换（用户 08-12 确认）
- 默认视图：卡片（用户 08-12 确认）；切换后 localStorage 持久化

## Acceptance Criteria

- [ ] 页面提供卡片/表格切换；全新用户首次进入默认为卡片视图；切换后刷新页面保持所选视图
- [ ] 卡片视图下单卡高度紧凑，一屏可见卡片数明显多于原表格行数（1440px 宽度下 ≥ 6 张）
- [ ] 表格视图下状态列不再竖排 4 个 Badge，操作列直出按钮 ≤ 2 个
- [ ] 筛选区默认单行展示，其余筛选项折叠在「更多筛选」内且激活数量可见
- [ ] 两种视图下：3 类搜索、4 类筛选、仅失败、分页、R 刷新、`sessionId` 高亮定位、续聊/停止/日志/变更全部功能正常
- [ ] SSH 会话在两种视图下能看到 SSH 标识、目标主机与 artifact 受限提示
- [ ] 新增文案 zh-CN + en 均已翻译，无硬编码中文/英文
- [ ] `npm run build`、`npm run lint`、`npm run format:check`、`npm run test:ci` 全部通过

## Out of Scope

- 后端接口、筛选逻辑、分页逻辑的行为变更
- 其他页面（Dashboard/项目/员工等）的布局调整
- 会话数据模型或新增字段
