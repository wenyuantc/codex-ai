# PRD · A2 会话日志复制与导出

父任务:`08-12-product-gap-wave` · 优先级 N-P1

## 需求

1. `CodexTerminal` 头部工具栏新增「复制全部」与「导出 .log」按钮,复用已有 `lines` 数据源。
2. 复制:全部日志行拼接进剪贴板,成功给出轻提示。
3. 导出:保存为 `.log` 文本文件(文件保存对话框),文件名含任务/会话标识与时间戳。
4. 所有引用 `CodexTerminal` 的场景(任务日志弹窗、Session 管理、员工运行终端)自动获得该能力。

## 验收标准

- [ ] 复制/导出按钮在终端头部可见,空日志时禁用。
- [ ] 复制内容与可见日志一致(含过滤前的全部行,按现状 `lines` 数据源为准)。
- [ ] 导出的 .log 文件内容完整、换行正确。
- [ ] 文案 i18n zh/en 齐全。
