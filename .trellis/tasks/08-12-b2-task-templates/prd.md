# PRD · B2 任务模板

父任务:`08-12-product-gap-wave` · 优先级 N-P2

## Goal

用户能把重复性任务存成模板，再用 `{{变量}}` 一次生成多条任务（例如 20 个模块名 → 20 条待办），而不必手工建 20 次、写 20 遍描述。

## Background

看板已能新建、批量改状态、批量运行，但没有任务模板。`prompt_templates.rs` 存的是 AI 提示词，与任务无关。痛点见 `docs/analysis/08-product-gap-2026-08-11.md` §B2。本波顺序 A1 → A2 → B1 → **B2** → C1 → D1；前三项已归档。

## Requirements

1. **建模板**：任务右键「存为模板」；看板「模板」入口可手动新建、编辑、软删除。从任务保存时复制：标题、详情、优先级、是否 worktree、标签**名**、子任务**标题**（子任务状态不复制）。
2. **变量**：仅标题与详情支持 `{{变量名}}`。套用时按组填值，一次可多组。缺变量报中文错，不静默留空。标签名与子任务标题按模板原文复制，不参与变量替换。
3. **套用落点**：任务始终建在当前看板项目。可选指定经办人/审查员。与手建任务同一规则：默认自动质控 / 质控开启必须有审查员；`use_worktree` 以模板为准；每条新任务写 `task_created`。
4. **可见性**：模板可绑项目或全局（`project_id` 空）。看板列表 = 当前项目 + 全局。跨项目套用只带字段与标签名，不带员工/里程碑/附件。
5. **批量上限**：单次套用 1–100 组，与 `batch_update_tasks` 对齐。无占位且未传组时按 1 条原文创建。
6. **失败原子性**：缺变量、空标题、超限、质控缺审查员时整批失败，不留下半成品任务。
7. **文案**：活动日志记录模板创建/套用/删除；仪表盘中文可读；UI i18n zh-CN + en。

## Acceptance Criteria

- [x] 右键「存为模板」可用；看板可管理模板（新建/编辑/软删除）。
- [x] 套用一组或多组变量可批量生成任务，占位替换正确；标签按名称在目标项目复用或新建；子任务标题就位且为待办。
- [x] 超过 100 组、缺变量、空标题、自动质控缺审查员时失败且不产生新任务。
- [x] 套用到本地与 SSH 项目走同一命令（本地 SQLite，不上传附件）。
- [x] 活动日志 `task_template_created` / `task_template_applied` / `task_template_deleted` 在仪表盘中文可读；i18n zh-CN + en 齐全。
- [x] Rust 单测覆盖变量提取/替换、缺变量、超限、套用含标签与子任务的 roundtrip。

## Out of Scope

- 模板文件导入/导出 UI（`export_tasks_json` envelope 只作 JSON 形状参考）。
- 预估工时（任务模型无此列）。
- 模板内存员工 ID、附件、依赖边、里程碑、计划正文、验收清单。
- 套用后自动批量运行（看板已有批量运行）。
- 改 AI 提示词模板（`prompt_templates`）。
