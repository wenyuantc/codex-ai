# PRD · B2 任务模板

父任务:`08-12-product-gap-wave` · 优先级 N-P2

## 需求

1. **建模板**:可从已有任务一键存为模板,也可手动创建;模板含标题模式、详情模式、优先级、工时、worktree 模式等可复用字段。
2. **变量机制**:模板标题/详情支持 `{{变量}}` 占位;套用时填变量值,支持一次填多组值批量生成 N 个任务(如 20 个模块名 → 20 个任务)。
3. **模板管理**:列表、编辑、删除;看板页有入口。
4. 套用模板创建的任务与手建任务无差别(走同一创建链路,含活动日志)。

## 约束

- 模板结构参考 `export_tasks_json` 的版本化 envelope 思路,便于将来导入导出。
- 批量创建复用/对齐 `batch_update_tasks` 的量级限制(单次 ≤100)。

## 验收标准

- [ ] 从任务「存为模板」入口可用;模板列表可管理。
- [ ] 套用模板,填一组/多组变量,批量生成任务成功且内容正确替换。
- [ ] 活动日志记录模板创建/套用;仪表盘中文可读;i18n zh/en 齐全。
- [ ] Rust 侧模板 CRUD 与变量替换有测试。
